# Space Grotesk

Self-hosted Latin variable font (weights 400-700), served without a third-party
request. Chinese text uses the configured local CJK font fallbacks.

- Upstream: https://github.com/floriankarsten/space-grotesk
- Asset: Google Fonts, Space Grotesk v22, Latin WOFF2 subset
