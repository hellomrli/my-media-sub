# v2.2.20 升级指南

```bash
docker compose pull && docker compose up -d
```

或用 WebUI 的在线更新，升级后会自行重启。本版本纯前端布局调整，无 schema 与后端行为变更。

## 改了什么

### 夸克网盘状态常驻左侧导航栏

原来它在工作台占一整张卡片，内容却只有四行状态。现在移到侧边栏底部（系统设置上方），任何页面都能看到连接状态、自动转存开关、今日签到与容量，卡片右上角有独立的检测按钮。工作台因此把整行让给了更新日历。

### 周视图改为纵向

横向七列的问题是：7 列在任何容器里都要挤到 118px 才放得下，窄一点就得横向滚动，而横向滚动条在移动端没有视觉提示，等于内容消失。

改成一天一行后，日期固定在行首（星期 + 日期 + 项数），当天的排期在右侧横向铺开；没有排期的日子收成一条窄行，不再是 470px 高的空盒子。条目卡也从竖版海报改成横版：缩略图 42×58 在左，剧名与集数在右，状态徽标和操作按钮在下方，行高从约 230px 降到约 190px。

手机上一行放一个条目，同样不需要横向滚动。

### 系统设置改为纯纵向单列

这是第三次调整这一页，前两次都走偏了：

- v2.2.18 用 `minmax(320px, 1fr)` 自适应多列 → 卡片一窄，三列字段被压到 140px，TMDB API Key 只看得见一个字
- v2.2.19 改成「够宽才分栏」（1500px 以上、每栏 560px）→ 输入框宽度够了，但卡片宽度仍随视口跳动，区块忽左忽右

**表单要的是稳定的行宽，不是塞进一屏。** 这版彻底不分栏：一列到底，最大 920px，居中，超宽屏留白而不是把输入框拉长。同时修掉了 v2.2.18 遗留的一条 `align-items: start`——它让纵向弹性列里的每个区块收缩到自身内容宽度，同一页里的卡片因此宽窄不一，这才是「卡片乱飞」的直接原因。

设置页现在会滚动，这是刻意的取舍：能舒服输入 > 一屏放下。

## 二进制部署

纯前端改动，手动升级必须替换整个 `static/` 目录。前端资源 `?v=2.2.20`，SW 缓存代次 `v2.2.20-sidebar-cloud-and-vertical-week-1`。
