# v2.2.19 升级指南

```bash
docker compose pull && docker compose up -d
```

或直接用 WebUI 的在线更新（「系统设置 → 版本更新」），从 v2.2.17 起在线升级会自行完成重启。

v2.2.19 不修改 JSON Store schema，也没有后端行为变更，纯前端布局调整。

## 先说一句：v2.2.18 的设置页是个错误取舍

上一版为了让设置页「一屏放下」，给每个标签页套了 320px 起的自适应多列。结果卡片一窄，里面原本按整行设计的三列字段被压到 140px 上下——TMDB API Key 输入框只能看见一个「留」字，根本没法输入。**一屏是次要目标，能用才是主要目标**，这一版把顺序摆正了：

- 视口低于 1500px：单列，字段按原本的整行布局展开
- 1500px 以上：分栏，但每栏至少 560px
- 栏内字段改用容器查询，按卡片自身宽度决定分几列，而不是跟着视口猜

实测 1440px 单栏时 RPC URL 输入框 530px、1920px 双栏时夸克 Cookie 输入框 660px，同时两种宽度下常用设置页依然是一屏。

## 工作台：更新日历成为主面板

**独立的「更新日历」页面下线，内容并入工作台**，顶替原来的「订阅看板」。理由很直接：打开工作台想知道的是「接下来哪部剧要更新」，而不是「最近检查过哪些订阅」。周/月/列表三种视图、日期导航和筛选全部保留。

`?tab=calendar` 的旧链接和 PWA 的「今日更新」「缺集」快捷方式会自动路由到工作台，不会 404。

**同时删掉了三张重复的卡片**：

- 「自动化执行」——失败计数已经在指标格里，明细在活动中心
- 「最近活动」——活动中心就是干这个的
- 「快捷入口」——六个入口全部与指标格或命令栏重复

工作台现在只剩 4 张卡片：概览与操作、运行指标、更新日历、夸克网盘。卡片仍可在右上角「编辑工作台」里排序和显隐。

**旧布局配置自动映射**：`hero` → 概览与操作，`library` → 更新日历，`operations` → 夸克网盘；已删除卡片的 id 静默丢弃，不需要手动重配。

## 手机端

窄屏没有「填满一屏」的高度约束，日历列表会把整页撑到上万像素（实测 10906px）。现在面板卡片有视口相对的高度上限，长内容在卡片内部滚动，页面高度回到 1574px。

## 二进制部署

本版本全是前端改动，手动升级必须替换整个 `static/` 目录，只换二进制不会有任何变化。前端资源 URL 带 `?v=2.2.19`，Service Worker 缓存代次 `v2.2.19-calendar-dashboard-and-forms-1`。
