# v2.8.5 升级指南

[文档入口](index.md) · [完整变更](../CHANGELOG.md) · [GitHub Release](https://github.com/hellomrli/my-media-sub/releases/tag/v2.8.5)

v2.8.5 与 v2.8.4 使用相同的 JSON Store schema、备份格式和 API 契约，无需迁移。升级前保留一份已核对的备份，不要删除 `data/`、`runtime/` 或原有 `.env`。

## 部署与核对

Docker Compose 用户在原部署目录运行：

```bash
docker compose pull
docker compose up -d
curl --fail http://127.0.0.1:56001/health
```

固定版本时使用 `ghcr.io/hellomrli/my-media-sub:2.8.5`。确认健康检查返回 `"version":"2.8.5"`，并核对原订阅、设置和待处理任务。WebUI 在线更新只替换程序和静态文件；要同时更新容器基础系统，请拉取镜像并重建。

独立部署按[发布包安装步骤](deployment.md#使用-linux-x86_64-发布包)下载归档与同名 `.sha256`，校验后停服，同时替换程序和完整 `static/`。本次 Release 未提供 `.minisig`。配置了 `SELF_UPDATE_PUBLIC_KEY` 的客户端会拒绝无签名归档；请使用镜像或按自己的信任策略手动升级，不要关闭强制验签。

## 升级后需要注意什么

- 新备份写入并通过隔离恢复验证后才清理旧副本。`BACKUP_MAX_STORAGE_MB` 是轮换后的预算，不是临时磁盘用量上限；应另外预留新归档和验证目录的空间。旧备份仍可恢复，其中的根目录 `.lock` 会被忽略。
- 固定画质订阅只转存当前仍符合规则的版本。维护期间发现但尚未转存的完结集，会在关闭维护后的下次检查补转。若旧版已误标完结，请对受影响的订阅选择“重新追更”并“立即检查”；不会批量重开手动完结的订阅。
- 使用 Aria2 的多季订阅可在下载管理核对同名文件的目标季目录。如果目录留空且无法读取下载器默认目录，本版不会仅凭文件名复用已有任务。
- PWA 资源版本为 `2.8.5`，缓存代次为 `v2.8.5-shell-1`。在线打开应用，出现提示后选择“立即更新”；访问过 API 文档后再离线打开首页，应仍显示工作台。

## 回滚

停服后换回 `2.8.4` 镜像，或旧二进制及其配套 `static/`。不需要回滚数据库；同一个数据目录不要同时启动新旧实例。外部网盘转存和已提交的下载不会随程序版本自动撤销。
