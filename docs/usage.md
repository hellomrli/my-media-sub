# 第一次保存电影或订阅剧集

[返回文档入口](index.md)

完成本页后，你可以在自己的夸克网盘看到所选电影或新集，并在应用中检查任务结果。

## 快速安装

先完成 [README 的 Docker 快速开始](../README.md#快速开始)，确认 `/health` 返回正常状态。独立二进制、远程连接和启动排错见 [部署指南](deployment.md)。

## 快速开始

1. 登录 WebUI，进入系统设置。
2. 填写夸克 Cookie 并使用测试按钮。没有 Cookie 时，季度探测和转存会返回“未配置夸克 Cookie”。
3. 暂时不配置 PanSou、TMDB 或下载器，也可以直接添加分享链接。需要搜索、海报、下载或通知时按 [集成指南](integrations.md) 接入。

## 保存一部电影

1. 点击添加媒体，选择“电影”，粘贴可访问的夸克分享及提取码。
2. 选择 1080P / 4K 等画质，再选一个具体正片。同画质有多个剪辑版本时确认文件名与大小。
3. 设置网盘目标目录。已接入 Aria2 时，可同时下载到本地，也可仅保存网盘。
4. 执行“下载保存”，在活动中心检查后台任务，成功后打开自己的网盘目标目录。

电影不创建持续订阅，只保存所选正片。目标目录已有同名文件时先核对已有资源；下载提交失败时先检查下载管理，再从网盘页继续下载，避免重复转存。具体行为见 [电影保存与画质](media-save-quality.md)。

## 订阅一部剧

1. 添加媒体，选择剧集或动画，粘贴分享链接。
2. 确认标题与季度。可追单季、`1-4` 连续多季，或 `1,3` 跳季。
3. 选择目标目录、画质和是否自动转存。固定画质会保留到订阅规则；缺少该画质时等待更新。
4. 保存订阅，执行“立即检查”。
5. 在任务、活动和网盘目标目录核对新集。按规则可进行转存、重命名和同步下载。

检查返回新文件、新集数和识别明细；转存由异步 Job 执行，检查响应成功不等于网盘操作已完成。后续按订阅间隔继续检查。

旧电影订阅数据和手动操作仍保留，但不参与定时追更。修改剧集画质只影响后续更新，不清空已有进度。

## 检查结果

| 现象 | 下一步 |
|---|---|
| 分享无法探测 | 核对 Cookie、链接、提取码和分享是否失效 |
| 没有匹配的画质 | 查看文件名与目录标记；固定画质不自动回退，未标注不代表实际低画质 |
| 查不到剧名 | 手工确认标题、年份和季度，再按 [剧名匹配](title-matching.md) 核对 TMDB 返回与重试边界 |
| 检查成功但未转存 | 查看是否仅通知、是否有新集，以及异步任务状态 |
| 转存完成但本地没有文件 | 核对 Aria2 配置、下载器自己的目录和下载管理 |
| 分享失效需要换源 | 先预览候选与画质/进度匹配，再按 [换源说明](source-quality.md) 应用 |
