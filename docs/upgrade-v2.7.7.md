# v2.7.7 升级指南

v2.7.7 不修改 JSON Store schema，可复用 v2.7.6 的数据与配置。升级前核对备份，保留 `data/` 和 `runtime/`；不要用新安装命令覆盖现有 `.env`。

## Docker Compose

在原部署目录执行：

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100
curl --fail http://127.0.0.1:56001/health
```

确认健康检查返回 `"version":"2.7.7"`。固定镜像版本的用户应将镜像更新为 `ghcr.io/hellomrli/my-media-sub:2.7.7`。

**本次建议拉取并重建容器，而不只执行 WebUI 在线更新**：在线更新会替换程序和静态资源，但不能更新容器基础层的系统软件包。新版镜像构建会拉取新基础镜像，并重新安装可用的系统安全更新；仍使用 bookworm 保持二进制兼容性。

## 独立二进制

从 [v2.7.7 Release](https://github.com/hellomrli/my-media-sub/releases/tag/v2.7.7) 下载 Linux x86_64 归档及 SHA-256 文件，校验后停服替换程序和**完整 `static/` 目录**，保留原数据、配置与备份。详细命令见 [部署参考](usage.md#快速安装)。

不要只换二进制。页面资源 URL 与 Service Worker 缓存代次均更新为 2.7.7；若旧页面仍然打开，升级后重新加载。

## 本次变化

- **剧名回退**：TMDB 首次查询为空后继续尝试别名、篇章主名、标点与中文空格变体，最多 6 个名称，共享 30 秒标题查询预算。只有命中才应用标准标题，保留年份提示与手工季度选择；错误 Key、限流和网络失败不会被当成空结果改名重试。
- **搜索界面**：图片候选逐级回退，旧搜索响应和计时器不能覆盖新的结果；桌面与手机均有浏览器回归。
- **依赖维护**：reqwest 0.13.5、Alpine 3.17.5 及兼容 Rust 依赖更新。TLS 保留 ring 与 Mozilla 根证书、证书及主机名校验、更新下载主机白名单；转存等非幂等 HTTP 请求不自动重放。
- **工具链说明**：正式构建使用 Rust 1.99.1，`rust-version = "1.89"` 只是最低源码兼容版本。Docker 与发布二进制用户不需要自行安装 Rust。
- **文档整理**：README 前置安装与首次订阅流程，详细使用、开发和历史记录迁入独立文档；依赖版本、审计范围和暂不能升级的上游限制见 [安全审计](security-audit.md)。

## 升级后核验

1. 检查 `/health` 的版本号和启动日志，确认订阅、任务、设置仍在。
2. 在订阅编辑器用实际目标剧名试一次智能识别，确认尝试记录、TMDB 命中标题、年份与季度；本地自动测试不使用真实 TMDB Key。
3. 检查一次资源搜索和图片显示；如使用 Web Push，手工发送一条测试通知并确认设备收到。

如需回滚，先停服并保存当前数据副本，再换回旧版程序和配套静态资源或固定旧镜像；不要让两个实例同时使用一个数据目录。
