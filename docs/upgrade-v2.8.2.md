# v2.8.2 升级指南

[返回文档入口](index.md) · [完整变更](../CHANGELOG.md)

v2.8.2 完善界面操作、状态反馈和文字可读性，不改变 JSON Store schema 或既有 API 契约，可直接复用 v2.8.1 / v2.8.0 的数据与配置。升级前核对备份，保留 `data/`、`runtime/` 和原 `.env`。

## Docker Compose

在原部署目录执行：

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100
curl --fail http://127.0.0.1:56001/health
```

确认健康检查返回 `"version":"2.8.2"`。固定镜像版本的用户改为 `ghcr.io/hellomrli/my-media-sub:2.8.2`。

拉取镜像并重建容器可同步获取运行层系统补丁；仅执行 WebUI 在线更新会替换程序和静态资源，不会更新镜像基础层。

## 独立二进制与在线更新

从 [v2.8.2 Release](https://github.com/hellomrli/my-media-sub/releases/tag/v2.8.2) 下载 Linux x86_64 归档及同名 SHA-256 文件，校验后停服，替换程序和**完整 `static/` 目录**，保留数据、配置与备份。操作参考 [发布包部署](deployment.md#使用-linux-x86_64-发布包)，在线更新信任配置见 [Docker 在线更新](docker-online-update.md)。

本版页面资源使用 `?v=2.8.2`，PWA 缓存代次为 `v2.8.2-ui-usability-7`。重新加载旧页面；已安装的 PWA 收到更新横幅后点击“立即更新”。原有主题、订阅视图和工作台布局偏好继续保留。

## 行为变化与核验

1. 确认 `/health` 返回 `2.8.2`，原订阅、任务和设置仍在。
2. 手机订阅页通过“更多”展开批量操作；设置概览可折叠，当前页面导航及下载分类标签保持可见。跳季订阅的详情标签正确显示为“第 1,3 季”。
3. 工作台点击失效订阅、失败任务或未读通知可直达对应筛选；页头刷新会同时更新日历。编辑布局时至少保留一张卡片。
4. 弹窗打开后键盘焦点进入面板，Tab / Shift+Tab 在可见控件之间循环；检查浅深色主题下徽标、补集提示和流水线编号是否清晰。
5. 连接状态由实际请求更新。任务事件流断开但普通请求仍成功时显示“正在重连”；请求无法到达服务时显示“服务未响应”与重试入口。
6. 下载任务空闲时可正常暂停、继续、重试、停止或删除；执行操作时只禁用该任务的按钮，其他任务仍可操作。

自动浏览器回归使用本地测试数据，不代替真实夸克保存、Aria2 下载、TMDB 查询或 Web Push 送达验证。

## 发布核验（2026-11-15）

GitHub CI、Release 与版本镜像均已成功。实际下载的发布归档通过 SHA-256 与 GitHub 资产摘要检查，随包 106 个静态资源和文档文件与发布 tag 一致；云端正式二进制及配套资源通过启动、Docker 入口初始化，以及真实 v1.3.0 / v2.8.1 数据升级 smoke。工作流链接、归档校验和与镜像摘要见 [发布台账](roadmap.md)。

本次发布提供 SHA-256 校验文件，未配置 minisign 签名，因而没有 `.minisig`。已设置 `SELF_UPDATE_PUBLIC_KEY` 的在线更新客户端会拒绝无签名归档；这些部署可按上面的 Docker Compose 或独立二进制步骤升级。签名与信任配置详见 [Docker 在线更新](docker-online-update.md)。

## 回滚

停服后换回 v2.8.1 镜像或旧二进制与配套 `static/` 即可。不需要数据迁移；同一个数据目录只运行一个实例。
