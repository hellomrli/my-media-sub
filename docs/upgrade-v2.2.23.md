## 改了什么

日历追剧卡片的缩略图随行高分档放大。行高由视口高度按七行均分，因此缩略图按视口高度分三档：

| 视口高度 | 缩略图 |
|---|---|
| < 1010px（如 1440×900） | 46×61 |
| ≥ 1010px（如 1920×1080） | 54×72 |
| ≥ 1250px（如 2560×1440） | 64×85 |

卡片宽度随档位同步放宽，海报与卡片的比例保持协调。实现用的是视口高度断点而不是百分比高度——后者在 flex 布局链里解析不稳定。
