# v2.2.24 升级指南

```bash
docker compose pull && docker compose up -d
```

也可以在 WebUI「系统设置 → 维护 → 在线更新」中切换到 v2.2.24。JSON Store schema 没有变化，现有 `data/` 可直接保留。

## 改了什么

- Aria2 已停止任务窗口从 50 提升到最近 1000 条，最新完成、失败与移除记录会正常显示。
- 下载页仅在存在活动或排队任务时进行 2 秒快速轮询；快速轮询只读取运行队列，任务结束时单独查询一次最终状态并追加记录，空闲后立即停止。
- 新增「清空记录」操作，清空前会先处理尚未落盘的下载完成状态。
- 完成与失败历史按每批 100 条渲染，避免一次创建千条 DOM。
- 修复 PWA 更新监听器重复累积的问题。

## Aria2 配置

页面最多请求 1000 条停止记录，但实际可见数量仍受 Aria2 的 `max-download-result` 限制。Aria2 默认值通常是 1000；如果自行调低过，需要同步调大并重启 Aria2。已经被 Aria2 淘汰或清空的旧记录无法恢复。

## 二进制部署

本次同时包含后端 API 与前端改动，必须一起替换二进制和整个 `static/`，不要只覆盖其中一项。前端资源版本为 `?v=2.2.24`，Service Worker 缓存代次为 `v2.2.24-aria2-history-on-demand-1`。
