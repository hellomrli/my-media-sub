# v2.2.21 升级指南

```bash
docker compose pull && docker compose up -d
```

或用 WebUI 在线更新（会自行重启）。无 JSON Store schema 变更。

## 工作台：日历一屏放完

- 周视图七行**等高**，有排期和无排期的日子同高，整周恰好占满屏幕剩余高度，不再滚动页面。
- 条目卡压缩为单行横版：缩略图在左，剧名与 S/E 集数一行，状态徽标与「详情/检查/补集」靠右。同一天排期过多时只在那一行内横向滚动，行高恒定。
- 日历工具栏收成一行（窄窗口自动换行）。
- **运行指标一行整体移除**——追更中/已完结在订阅页、失败任务与未读通知在活动中心都有，重复展示只占高度。工作台现在只有「概览与操作」和「更新日历」两张卡片（编辑工作台仍可排序/显隐）。

## 侧边栏

- 夸克网盘卡片改用与「自动化节点」相同的卡片风格，内容精简为三项：**账号状态、签到状态、容量**（转存开关不再展示，配置入口在系统设置）。
- 「自动化节点」新增**正在下载数量**与**实时下载速度**。数值在工作台或下载任务页停留时实时刷新。

## 修复

保存工作台布局时更新日历卡片会被静默丢掉：v2.2.19 把日历并入工作台，但后端 `dashboard_widgets` 白名单没有同步加入 `calendar`，保存的布局经过过滤后日历消失，重新打开工作台只剩概览一张卡。已补全白名单；此前受影响的布局在下次保存时自动恢复正常。

## 二进制部署

需同时替换二进制与 `static/`。前端资源 `?v=2.2.21`，SW 缓存代次 `v2.2.21-single-screen-calendar-1`。
