# v2.2.25 升级指南

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 -f
```

v2.2.25 不修改 JSON Store schema，可直接复用 v2.2.24 的 `data/`。

本版本移除已废弃的媒体库刷新功能和日历手动排期功能，代码精简 390 行。前端资源 URL 带有 `?v=2.2.25`。

如果使用二进制部署，必须同时替换归档中的整个 `static/` 目录；只替换二进制会继续运行旧前端代码。

## 功能移除说明

### 媒体库刷新（已移除）
- Emby/Jellyfin/Plex 刷新配置已从设置页面移除
- `media_library` 服务及相关代码已删除
- 此功能已被订阅驱动的自动化流程替代

### 日历手动排期（已移除）
- 日历页面不再显示排期选择器
- 手动排期后端逻辑已删除
- 日历现在完全依赖订阅驱动的自动更新

如果你之前依赖这些功能，请在升级前评估影响。
