# v2.8.1 升级指南

v2.8.1 为前端视觉重构与活力化升级版本，不修改 JSON Store schema 或 API 契约，可直接复用 v2.8.0 / v2.7.7 的数据与配置。升级前核对备份，保留 `data/`、`runtime/` 和原 `.env`；不要用新安装命令覆盖现有管理员密码。

## Docker Compose

在原部署目录执行：

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100
curl --fail http://127.0.0.1:56001/health
```

确认健康检查返回 `"version":"2.8.1"`。固定镜像版本的用户应改为 `ghcr.io/hellomrli/my-media-sub:2.8.1`。

建议拉取镜像并重建容器，而不只执行 WebUI 在线更新：在线更新替换程序与静态资源，不能更新容器基础层的系统软件包。新版镜像构建继续获取基础镜像与运行层补丁，保留 bookworm 二进制兼容性。

## 独立二进制与在线更新

从 [v2.8.1 Release](https://github.com/hellomrli/my-media-sub/releases/tag/v2.8.1) 下载 Linux x86_64 归档和同名 SHA-256 文件，校验后停服替换程序与**完整 `static/` 目录**，保留数据、配置和备份。命令见 [部署参考](usage.md#快速安装)，在线更新的信任与签名要求见 [Docker 在线更新](docker-online-update.md)。

不要只换二进制。页面资源 URL、编译样式与 Service Worker 缓存代次同时更新为 2.8.1，升级后重新加载旧页面。已有深色主题和表格视图偏好继续保留；没有偏好时默认使用暖米白浅色主题与海报墙。

## 行为与视觉变化

- **活力色彩与温润质感**：浅色主题采用暖米白底色与纯白高光卡片，深色主题采用午夜影院配色；引入翡翠绿（主色）、珊瑚橙（强调色）、电光蓝、极光紫与琥珀黄多维色板，搭配多光源极光环境背景与柔和微点阵纹理。
- **多彩分区导航**：桌面侧边栏与移动端标签栏按功能模块赋予独立色彩（工作台翡翠绿、资源搜索珊瑚橙、订阅管理极光紫、网盘电光蓝、下载管理青蓝、活动中心琥珀黄、系统诊断翠绿），激活态具有渐变胶囊与发光图标底座，桌面侧栏保留彩色指示条。
- **工作台与卡片层次强化**：统计卡采用四色侧边高光条；指挥台 Hero 卡片配备渐变标题与高对比度 `1080P` / `4K` 悬停响应票根；海报墙悬停抬升与光影反馈更鲜明，进度条升级为三色渐变。
- **可读性与动态偏好**：主按钮、分段控件在浅深色主题及悬停状态保持文字对比度，激活导航图标改用深色前景；系统开启减少动态效果时，不再等待海报错峰入场。
- **数据与接口零变更**：订阅、任务、设置、电影保存与剧集画质规则与 v2.8.0 完全兼容，无需额外数据迁移。

## 升级后核验

1. 确认 `/health` 返回 `2.8.1`，原订阅、任务、设置和主题偏好仍在。
2. 强制刷新浏览器（或点击 PWA 更新横幅的“立即更新”），确认浅色 / 深色主题切换、多彩导航、工作台卡片和海报墙样式正常加载。

## 回滚

停服并换回旧镜像或旧二进制与配套 `static/` 目录即可；不要让两个实例同时使用同一个数据目录。
