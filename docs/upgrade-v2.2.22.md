# v2.2.22 升级指南

```bash
docker compose pull && docker compose up -d
```

或用 WebUI 在线更新（会自行重启）。纯前端改动，无 schema 与后端行为变更。

## 改了什么

### 工作台日历

- **追剧卡片贴合行高**：卡片在等高的行内拉伸铺满，缩略图放大到 42×56。
- **卡片精简**：状态徽标（「本周待更新」等）与「详情/检查/补集」按钮移除——整张卡片就是入口，点击直达订阅详情，检查与补集在详情页里做。集数（`S1 · E152`）移到卡片右侧，等宽字体。
- **周日置顶**：周视图第一行是周日，之后是周一至周六；月视图表头与网格同步。范围标签相应变为周日到周六。
- **字阶统一**：标题 16 / 正文 14 / 辅助 12，日期数字 20，不再忽大忽小；「上海时区 · 检查计划不等于播出计划」说明移除。

### 侧边栏

「自动化节点」分两行：订阅与任务一行，**下载数量与实时速度**另起一行。

### 浅色主题不再刺眼

此前浅色模式是纯白面板（`#FFFFFE`）+ 近黑文字的高对比组合，大面积高亮很刺眼。新调色板整体调暗为暖纸色：

| | 旧 | 新 |
|---|---|---|
| 页面背景 | `#F9F8F5` | `#EEEAE2` |
| 面板 | `#FFFFFE`（纯白） | `#F6F2EB` |
| 正文 | `#1C1B19`（近黑） | `#2D2923`（暖深灰） |

输入框、边框、阴影与全部语义色（主色/成功/警告/危险）同步柔化，保持对比度可读。**深色主题完全不变。**
