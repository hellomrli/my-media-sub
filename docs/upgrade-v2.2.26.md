# v2.2.26 升级指南

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 -f
```

v2.2.26 不修改 JSON Store schema，可直接复用 v2.2.25 的 `data/`。

本版本在工作台日历增加最高已转存集数与来源落后提醒，并将换源候选探测改为并发限时。升级后不需要重新创建订阅；已有元数据、已知集数、转存进度和换源历史都会继续使用。

STRM 功能暂时完全下线。旧 `settings.json` 和订阅记录中的 `strm_*` 字段仍可兼容读取，但设置页不再展示这些字段，API 也不会重新启用或生成 STRM 文件。已有本地 `.strm` 文件不会自动删除；如仍依赖它们，请在升级前保留 v2.2.25 部署并自行确认播放链路。

如果使用二进制部署，必须同时替换归档中的整个 `static/` 目录；只替换二进制会继续运行旧前端代码。
