# 电影保存与画质选择

WebUI 使用浅色青绿与杏橙配色，保留深色切换和已有主题偏好；订阅默认使用海报墙，也可继续使用表格。字体资源自托管，不需要访问外部字体服务。

## 保存一部电影

1. 在“添加媒体”或搜索结果操作中选择“电影”。电影只有“选择片源”和“下载保存”两步，不创建持续订阅。
2. 粘贴夸克分享链接及提取码。系统读取分享内的文件和目录，列出 1080P、4K 等画质方案。
3. 选择画质，再选择正片文件。同画质可能有导演剪辑版、不同编码或不同文件大小的版本，电影每次只保存一个文件。
4. 确认网盘保存目录。已配置 Aria2 时默认同时下载，也可切换为仅保存到网盘；未配置 Aria2 时仅保存网盘。
5. 在活动中心查看保存任务，在下载管理查看 Aria2 进度。电影本地目录不添加 `Season N`。

分享探测和转存需要夸克 Cookie；本地下载需要 Aria2 RPC。保存任务会重新探测并核对文件 ID 与画质，分享内容变化后不会改存另一个版本。目标目录已有同名文件时停止转存，请确认已有资源或改用其他目录，以免下载错误版本。

网盘保存成功后会重新读取自己网盘中的文件 ID，并核对已知文件大小，不使用分享文件 ID 获取下载地址。若本地下载提交失败，保存结果与错误仍保留；先核对下载管理，再从网盘页继续下载，不要重新转存。已有云端保存证据的任务不允许重试转存。

## 剧集选择画质

剧集与动画仍支持持续追更、季度选择、重命名和同步下载。内容页选择画质后，规则中的 `preferred_resolution` 会持久化；新增检查、补转、重命名预览、订阅详情与换源进度使用同一画质口径。

| 选项 | 行为 |
|---|---|
| 1080P / 4K 等固定画质 | 只处理这个画质，优先识别文件名，其次识别最近的画质目录 |
| 未标注画质 | 只处理未找到明确分辨率标记的文件 |
| 按规则自动 | 不锁定画质，沿用原有的同集择优策略 |

固定画质不存在时等待，不回退到其他画质。修改画质不清空已知集数与转存历史，只影响后续更新；如需替换已保存的旧版本，应另行保存或手动处理。

## 探测边界

- 识别文件名中的 `1080p`、`2160p`、`4K`、`UHD` 等标记，以及 `4K/Season 1/01.mkv` 这样的目录结构。
- 文件名优先于目录，最近的画质目录优先于更上层的合集目录；同时写有 1080P 和 4K 的合集名称不作为单个文件的画质证据。
- 这是资源命名识别，不读取视频码流，也不把 HDR 或文件大小直接当成实际分辨率。
- 预告、花絮、解说及 sample 文件不作为电影正片选项。分享过大或部分目录读取失败时显示结果可能不完整；电影仍可精确选择已经找到的文件。
- 旧订阅缺少 `preferred_resolution` 时默认为自动，不需要迁移 JSON。旧电影记录保留，但不再参与定时追更；已有后台转存任务与手动操作不被取消。

## API

所有接口继续使用现有管理员认证或相应的自动化 Token 权限。

`POST /api/subscriptions/seasons` 的响应在原有季度字段外新增：

- `qualities`：按画质分组的标签、视频数、总大小和路径样本。
- `media_files`：可选正片文件的 `file_key`、文件名、父路径、大小与画质。
- `partial` / `probe_message`：不完整探测及提示信息。

`POST /api/transfer` 可携带 `save_options` 发起一次性媒体保存，不创建订阅：

```json
{
  "url": "https://pan.quark.cn/s/example",
  "passcode": "",
  "save_options": {
    "title": "示例电影",
    "media_type": "movie",
    "preferred_resolution": "2160p",
    "file_ids": ["从 media_files.file_key 选择的分享文件 ID"],
    "target_dir": "/NAS/电影/示例电影",
    "sync_download_enabled": true,
    "sync_download_dir": "/downloads/movies/示例电影"
  }
}
```

省略 `save_options` 保持原有整份分享转存的 API 语义。电影推荐始终传入一个明确的 `file_ids`；空选择且存在多个正片时会被拒绝。下载目录留空时由 Aria2 使用自身默认目录。

创建或更新剧集时，将 `rules.preferred_resolution` 设置为 `1080p`、`2160p` 等；空字符串代表自动，`unknown` 代表未标注。支持 4K / UHD 等别名，后端保存为规范值。换源预览新增 `quality_matches`，缺少所选画质的候选不能应用，即使使用强制换源也不能绕过画质匹配。
