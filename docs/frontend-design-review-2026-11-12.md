## 第二轮：后续建议的落实（2026-11-13 至 2026-11-15）

首轮列出的四项建议均已在同一工作区完成。

| 建议 | 处理 | 验证 |
|---|---|---|
| 压缩手机首屏的工具区 | 订阅页在手机上只留状态筛选和“添加媒体”，批量检查、刷新元数据、全选与视图切换收进“更多”；设置概览在手机上默认收起，只显示完成度和未完成的必需项，展开状态按设备记住 | 390px 下工具区高度、首张海报位置、概览收起/展开与桌面常显由浏览器回归断言 |

| 简化工作台布局编辑 | 至少保留一张卡片：最后一张的隐藏按钮禁用并说明原因；移除无法跨区域生效的上移/下移；恢复卡片按目录顺序插回 | 单元测试与浏览器回归 |
| 整理重复样式，补齐弱文字 | 见下 | 见下 |

**重复样式。** `.btn-primary` / `.btn-secondary`（原 3 处）、`.app-content`（原 8 处）、`.settings-pane`（原 3 轮互相覆盖的布局）各自合并为一处定义，`tailwind/input.css` 减少约 80 行。合并前后用真实 Chrome 在浅色/深色、10 个宽度（340–1520px）下逐元素比较全部计算样式，含 `::before` / `::after` 以及按钮的悬停、聚焦、按下状态，共 28 个场景、约 6.9 万个元素快照。差异只有两类，均为有意保留：

- 禁用的按钮悬停时不再变色和上浮。此前旧的 `.btn-*:hover` 规则没有排除禁用状态，会盖掉渐变底色。
- 设置窗格去掉了两个在弹性布局下不生效的网格属性，以及模板上对应的 `is-wide` 标记。

**弱文字。** 55 条把强调色（主色、成功、警告、危险、青色）直接用作文字色的规则改用首轮引入的文字色令牌，覆盖搜索结果标签与风险提示、预览提示、订阅详情的集数格与流程步骤、下载流程、日历指标与操作、状态横幅、设置概览和工作台编辑条。图标、品牌字样等装饰元素保持原色。此外修正两处实测不达标的文字：

- 海报上的画质徽标原为固定的半透明黑底，浅色主题下是深灰字压深灰底；“有效 / 失效 / 未检测”徽标沿用通用的半透明底色，压在深色画面上几乎看不见。两者都改为随主题的不透明底色，对比度不再取决于下方的图片。
- 设置概览的可选项原先整块 72% 透明，标题实测 3.79:1；改用虚线边框区分，不再淡化文字。

浏览器回归新增像素级对比度检查：对每个被测元素截两张图，一张隐藏全部文字（真实底色），一张把元素铺满其文字色，逐像素取最差值，因此渐变、半透明叠层、海报和祖先透明度都按实际渲染计入。海报上的徽标另外压在纯黑和纯白的海报上各测一遍。浅色与深色主题各测 51 个元素，最低分别为 4.97:1 和 4.87:1，门槛 4.5:1。把搜索标签改回装饰色后该检查按预期失败（2.65:1）。这些数值只针对被测元素，不代表全站无障碍认证；未纳入检查的页面状态（例如有真实下载任务的流程条）只做了规则替换，没有逐一实测。

**按钮内边距。** 复核截图时发现，只写 `class="btn-primary"` 而不带 `px-*` 的按钮没有任何内边距，文字贴着边框：诊断页的全部操作按钮、设置页的“保存全部设置”、日历空状态的“重试 / 清除筛选”、搜索页的“重新搜索”。这在 v2.8.1 中已经存在，不是本分支引入的。现在给三类按钮一个默认的左右内边距，写法不提高特异性，带 `px-*` 的按钮和各组件自己的按钮规则不受影响；计算样式比较确认变化只落在上述按钮上。浏览器回归新增检查：八个主页面在 1440px 和 390px 下，可见按钮的文字到边框不少于 6px；去掉默认内边距后该检查按预期失败。

回归脚本本身修正了一处时序问题：服务恢复后，断言在“未响应”横幅收起之前读取界面而偶发失败；现在等横幅消失再断言，横幅不消失仍会失败。

## v2.8.2 发布补充（2026-11-15）

已落实原有的带数据回归建议：浏览器通过页面实际使用的 API 加载多季剧集、六种流水线状态和四类下载任务，验证剧集筛选、订阅跳转以及 1440px / 390px 布局。新增检查发现并修复：

- 订阅详情“检查并补集”的辅助文字叠加 62% 透明度后只有 2.93:1 对比度；恢复不透明文字，流水线运行中编号也不再随透明度动画变淡，未启用步骤改用虚线边框。
- 状态接口返回原始订阅，没有列表的 `season_label` 展示字段；详情页和被同步的列表因此把跳季 `1,3` 显示成连续 `1-3`。标签回退逻辑现读取 `season_list`，新增通过状态接口加载的回归测试。
- 手机下载页的当前分类可能位于水平标签条外；切换分类、进入页面和缩放时只滚动标签条，使选中项保持可见。
- 操作按钮检查发现下载任务的空闲动作值为 `''`，直接传给 Alpine 的 `disabled` 绑定会设置禁用属性，导致暂停、继续、重试、停止和删除无法点击。模板改为明确布尔值，并新增空闲全部可操作、执行中只锁定对应任务的真实 DOM 断言。

浅深色对比度门禁已覆盖补集提示、所有剧集状态、流水线编号及说明、下载流程与操作按钮；每个主题实测 136 个元素，最低分别为 4.68:1 和 4.75:1，门槛 4.5:1。数值只代表被测元素。正式 v2.8.2 / Rust 1.99.1 二进制的 1440px / 390px 浏览器回归、719 项 Rust / 208 项前端测试、MSRV 与发布门禁通过；真实 v1.3.0 / v2.8.1 数据升级 smoke 通过。
