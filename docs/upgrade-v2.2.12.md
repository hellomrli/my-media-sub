# v2.2.12 升级指南

```bash
docker compose pull
docker compose up -d
docker compose logs --tail=100 -f
```

v2.2.12 不修改 JSON Store schema，可直接复用 v2.2.11 的 `data/`。

本版本将后台日志与通知中心合并为「活动中心」，下载任务按状态分区并为失败任务提供重试，同时改进订阅 Aria2 的 Season 目录适配和魔法剧名识别。前端资源 URL 带有 `?v=2.2.12`。

行为变化提示：

- 旧书签 `?tab=transferHistory` 会自动进入新的活动中心。
- Aria2 失败任务重试会保留原下载目录、输出名和请求头，并创建新的 GID；若上游临时下载地址已经失效，仍需重新提交下载来源。
- 剧集或动画下载目录明确以 `Season N` 结尾时保持不变；未指定 Season 时按文件识别结果自动创建对应目录。
- 魔法识别会移除标题尾部的画质、码率、语言与版本噪声，再使用清洗后的标题查询 TMDB。

如果使用二进制部署，必须同时替换归档中的整个 `static/` 目录；只替换二进制会继续运行旧前端代码。
